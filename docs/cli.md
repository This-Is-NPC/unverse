# CLI reference

Generated by `mise run docs-cli`. Do not edit by hand.

Use `unverse --help` for help, `unverse <group> --help` for a group, and
`unverse spec` for the same information as one JSON document. Every command
declares its effect: `read` commands change nothing in Dataverse or
PostgreSQL, and `write` commands require `--confirm`.

Exit codes follow [the global table](design.md#8-results-and-exits); a command
lists only the meanings it adds.

## config check

Validate a named local environment without contacting Dataverse.

- Effect: `read`
- Output formats: `human` (default), `json`, `csv`

`unverse config check [--config <path>] [--env <name>] [--format <human|json|csv>]`

### Flags

- `--config <path>`: Read this configuration file; overrides UNVERSE_CONFIG and the .unverse/config.json found upward from the current directory.
- `--env <name>`: Select a named environment profile; overrides UNVERSE_ENV, one of the two is required.
- `--format <human|json|csv>`: Select the output format (default human); human is indented JSON.

## deps list

Inspect direct required or dependent components using official Dataverse functions.

- Effect: `read`
- Output formats: `human` (default), `json`, `csv`

`unverse deps list [--config <path>] [--env <name>] [--format <human|json|csv>] [--object-id <guid>] [--component-type <integer>] [--reference-id <guid>] [--max-nodes <count>] [--max-edges <count>] [--max-queries <count>] [--no-bindings] [--direction <required|dependent|both>]`

### Flags

- `--config <path>`: Read this configuration file; overrides UNVERSE_CONFIG and the .unverse/config.json found upward from the current directory.
- `--env <name>`: Select a named environment profile; overrides UNVERSE_ENV, one of the two is required.
- `--format <human|json|csv>`: Select the output format (default human); human is indented JSON.
- `--object-id <guid>`: Select the underlying component object ID, not a solution membership ID.
- `--component-type <integer>`: Pair the object ID with its component type from this environment.
- `--reference-id <guid>`: Select a connection reference; its component type is resolved from metadata.
- `--max-nodes <count>`: Bound graph nodes to 2–1000 (default 200).
- `--max-edges <count>`: Bound graph edges to 1–10000 (default 1000).
- `--max-queries <count>`: Bound logical collection queries to 1–1000 (default 100), excluding WhoAmI, pagination, and retries.
- `--no-bindings`: Omit connection-binding enrichment; typed official dependencies remain.
- `--direction <required|dependent|both>`: Choose traversal direction (list: required; graph: both). Impact always follows dependents.

### Exit codes

- `7`: The graph or its dependency closure is incomplete.

Verify identities, relationships, decimals, and temporal values in PostgreSQL.

- Effect: `read`
- Output formats: `human` (default), `json`, `csv`

`unverse pg verify [--config <path>] [--env <name>] [--format <human|json|csv>] --manifest-file <path>`

### Flags

- `--config <path>`: Read this configuration file; overrides UNVERSE_CONFIG and the .unverse/config.json found upward from the current directory.
- `--env <name>`: Select a named environment profile; overrides UNVERSE_ENV, one of the two is required.
- `--format <human|json|csv>`: Select the output format (default human); human is indented JSON.
- `--manifest-file <path>` (required): Read a canonical transfer manifest or its result envelope.

### Exit codes

- `1`: Verification failed.

## apply

Apply a reviewed, fresh, environment-bound plan of any kind after explicit confirmation.

- Effect: `write`
- Output formats: `human` (default), `json`, `csv`

`unverse apply <plan-file> [--config <path>] [--env <name>] [--format <human|json|csv>] --confirm [--destructive]`

### Arguments

- `<plan-file>`: Read a reviewed plan or its JSON result envelope.

### Flags

- `--config <path>`: Read this configuration file; overrides UNVERSE_CONFIG and the .unverse/config.json found upward from the current directory.
- `--env <name>`: Select a named environment profile; overrides UNVERSE_ENV, one of the two is required.
- `--format <human|json|csv>`: Select the output format (default human); human is indented JSON.
- `--confirm` (required): Explicitly authorize the reviewed writes.
- `--destructive`: Authorize a plan whose effect is destructive; the invocation is then destructive.

### Exit codes

- `1`: A data or access plan was applied and post-apply verification failed.
- `7`: Operations remain or are blocked after a schema plan was applied.

## verify

Re-inspect the target and report whether a plan is satisfied, without writing.

- Effect: `read`
- Output formats: `human` (default), `json`, `csv`

`unverse verify <plan-file> [--config <path>] [--env <name>] [--format <human|json|csv>]`

### Arguments

- `<plan-file>`: Read a reviewed plan or its JSON result envelope.

### Flags

- `--config <path>`: Read this configuration file; overrides UNVERSE_CONFIG and the .unverse/config.json found upward from the current directory.
- `--env <name>`: Select a named environment profile; overrides UNVERSE_ENV, one of the two is required.
- `--format <human|json|csv>`: Select the output format (default human); human is indented JSON.

### Exit codes

- `1`: The plan is not satisfied.

## spec

- Output formats: `human` (default), `json`

`unverse spec [--format <human|json>]`

### Flags

- `--format <human|json>`: Select the output format (default human); human is indented JSON.

## init

Create .unverse/config.json from a template in the current directory.

- Effect: `write`
- Output formats: `human` (default), `json`

`unverse init [--format <human|json>] --confirm`

### Flags

- `--format <human|json>`: Select the output format (default human); human is indented JSON.
- `--confirm` (required): Explicitly authorize the reviewed writes.
