## connectors list

Find solution-aware connector metadata without retrieving definitions or credentials.

`unverse connectors list [--csv] [--solution-id <guid>] [--search <text>] --env <name> [--config <path>] [--json]`

### Options

- `--csv`: Write RFC 4180 CSV with spreadsheet-safe cells; nested values remain JSON.
- `--solution-id <guid>`: Select a solution by its environment-specific ID.
- `--search <text>`: Search names case-insensitively; table searches include labels and entity sets.
- `--env <name>`: Select a named environment profile.
- `--config <path>`: Read configuration instead of unverse.config.json.
- `--json`: Write one versioned JSON result to stdout.

## dependencies list

Inspect direct required or dependent components using official Dataverse functions.

`unverse dependencies list [--object-id <guid>] [--component-type <integer>] [--reference-id <guid>] [--direction <required|dependent|both>] [--max-nodes <count>] [--max-edges <count>] [--max-queries <count>] [--no-bindings] [--csv] --env <name> [--config <path>] [--json]`

### Options

- `--object-id <guid>`: Select the underlying component object ID, not a solution membership ID.
- `--component-type <integer>`: Pair the object ID with its component type from this environment.
- `--reference-id <guid>`: Select a reference; inspect requires it, dependency commands resolve its type from metadata.
- `--direction <required|dependent|both>`: Choose traversal direction (list: required; graph: both). Impact always follows dependents.
- `--max-nodes <count>`: Bound graph nodes to 2–1000 (default 200).
- `--max-edges <count>`: Bound graph edges to 1–10000 (default 1000).
- `--max-queries <count>`: Bound logical collection queries to 1–1000 (default 100), excluding WhoAmI, pagination, and retries.
- `--no-bindings`: Omit connection-binding enrichment; typed official dependencies remain.
- `--csv`: Write RFC 4180 CSV with spreadsheet-safe cells; nested values remain JSON.
- `--env <name>`: Select a named environment profile.
- `--config <path>`: Read configuration instead of unverse.config.json.
- `--json`: Write one versioned JSON result to stdout.

## dependencies graph

### Options

- `--html`: Write an offline interactive HTML canvas for a browser.

- `--depth <hops>`: Bound traversal to 0–10 hops from each root (default 3). A frontier remains explicitly unexplored.
- `--max-nodes <count>`: Bound graph nodes to 2–1000 (default 200).
- `--max-edges <count>`: Bound graph edges to 1–10000 (default 1000).
- `--max-queries <count>`: Bound logical collection queries to 1–1000 (default 100), excluding WhoAmI, pagination, and retries.
- `--no-bindings`: Omit connection-binding enrichment; typed official dependencies remain.
- `--csv`: Write RFC 4180 CSV with spreadsheet-safe cells; nested values remain JSON.
- `--solution-id <guid>`: Select a solution by its environment-specific ID.

- `--filter-file <path>`: Read an explicit OData filter expression from a file.
